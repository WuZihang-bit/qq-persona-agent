# 人格蒸馏流水线

把"一个人"变成"一份人格提示词"。四步：**解密 → 提取 → 画像 → 生成**。

> ⚠️ 仅限蒸馏**你自己**的聊天记录。蒸馏他人 = 处理他人个人信息，需要对方明确同意（见 ethics.md）。

## 总览

```
QQ NT 本地数据库(nt_msg.db, SQLCipher加密)
   │ ① 解密（tools/qqnt_decrypt，技术源自 QQBackup 社区）
   ▼
明文SQLite ──② 提取──► 我的消息 jsonl（tools/extract_messages）
   │
   ▼ ③ 画像（tools/analyze）
report.txt: 口头禅/标点习惯/emoji频率/活跃时段/会话分布
   │
   ▼ ④ 生成（手写+AI辅助，模板见 personas/example/）
persona.txt: 人格提示词 → 灌入 AstrBot
```

## ① 解密 nt_msg.db

Windows QQNT 的本地聊天库位于：
```
C:\Users\<用户名>\Documents\Tencent Files\<QQ号>\nt_qq\nt_db\nt_msg.db
```

- 格式：1024 字节自定义头（`QQ_NT DB` 魔数）+ SQLCipher 4 加密体
- 参数：AES-256-CBC / PBKDF2-HMAC-SHA512 4000 轮 / HMAC-SHA1 / 页 4096、reserve 48
- **密钥不落在文件里**，在登录中的 QQ 进程内存里（16 字节可打印 ASCII）

获取密钥的思路（技术细节见 [QQBackup 社区](https://github.com/QQBackup)，请遵守其许可证）：
1. 扫描 QQ 进程内存中的 16 字节 ASCII 候选
2. 用候选密钥对第一页做 HMAC-SHA1 校验，命中即为真密钥
3. 全库逐页 AES 解密 → 重组为标准 SQLite

> ⚠️ 只对你自己登录的账号/设备操作。此技术仅供数据恢复与个人备份。

## ② 提取自己的消息

解密后的库里，消息表的的关键列（数字列名）：

| 列 | 含义 |
|---|---|
| 40020 | 发送者 uid（u_ 开头） |
| 40033 | 群号（群聊表） |
| 40050 | 时间戳（unix 秒） |
| 40800 | 消息体（protobuf：40800=分段，45002=类型，45101=文本） |

步骤：
1. 在 `group_member3` 表（group_info 库）用自己的 QQ 号查到 uid
2. 遍历 `c2c_msg_table` + `group_msg_table`，过滤 sender == 我的 uid
3. 解析 40800 protobuf，导出 `{time, chat, is_group, text}` jsonl

参考 `tools/extract_messages.py`（含 protobuf walker）。

## ③ 风格画像

`tools/analyze.py` 会统计：
- **口头禅**：高频整条短消息、2/3字组合（过滤虚词）
- **标点习惯**：问句占比、感叹号使用率（真人往往极少用感叹号）
- **emoji 指纹**：unicode emoji 频次 Top（这是你的"签名组合"）
- **活跃时段**：几点最话痨、有没有深夜消息
- **长度分布**：中位数、≤10字占比（决定"短句铁律"的松紧）

## ④ 生成人格提示词

把画像交给 LLM（或手写），按 `personas/example/persona.txt` 的骨架填充：

```
身份基调 → 性格底色（本人自述校准，优先级最高）
说话风格 → 口头禅/标点/emoji 指纹 + 连发与字数规则
行为风格 → 场景应对表 + 承诺类话术
红线     → 隐私/危机转交/AI自证
```

**三条实践经验**（踩过坑的）：
1. **神似优先于形似**：口头禅是倾向不是任务，宁可整句没有，不要生硬堆砌——态度（幽默/反骨/傲娇）对了比词像更重要
2. **本人校准 > 语料统计**：统计只能算出"说过什么"，本人才能说清"是什么人"。让被蒸馏者本人试玩并纠偏，把纠偏固化进提示词
3. **负面清单要具体**：如"游戏英雄被动触发才聊""不主动提xx"，只写正面描述模型一定会过量使用

## 效果校准循环

```
上线 → 和分身聊 → 记录"不像"的点 → 改人格/插件参数 → 重启 → 再聊
```

典型纠偏案例（本项目真实经历）：
- 话痨 → 加"闲聊一次只发1条"铁律 → 后放宽为"连发但节流"
- 挂嘴边 → 加"被动触发才聊"负面清单
- 每句带emoji → 改为"含义精确匹配才发，多数消息本来就不带"
