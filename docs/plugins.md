# 插件说明

三个 AstrBot 插件，全部可独立使用。

## persona-humanizer（拟人化发送）

挂在 `on_llm_response` 钩子上，接管所有回复的发送。

| 能力 | 实现 |
|---|---|
| 随机延迟 | 1.5~4s 基础 + 按长度加"打字时间"，深夜更慢（×1.7，上限 20s） |
| 正在输入 | 私聊回复前调用 `send_typing()` |
| 多段连发 | LLM 回复含换行时拆成多条，间隔 0.8~2.2s 逐条发 |
| 全局节流 | 所有回复共用队列，两条消息最小间隔 3.5~7s，防止并发轰炸 |
| 真引用 | 群聊回复 >10 字自动引用触发消息；`[QUOTE:n]` 引用群窗口第 n 条 |
| 表情包 | `[[EMOJI:关键词]]` → 查表情库 index.json → 发真图；匹配不到静默吞标记 |

可调参数在 `main.py` 顶部：`SEND_GAP_MIN/MAX`、表情库路径等。

## group-lurker（群聊围观 + 主人捧场）

独立监听群消息（不依赖 @ 唤醒）。

- 每条群消息 **8% 概率**触发插话意愿，触发后等 2~6s（像刷群偶然看到）
- 把最近 14 条消息喂给 LLM 判断：有梗可接才说话，否则 `[SKIP]` 真沉默
- **主人发言**（QQ号可配）：高优先级接话，仅受短冷却约束，静默时段豁免
- 防打扰硬约束（代码强制，不靠 prompt）：同群冷却 8 分钟 / 每日上限 40 句 / 23:30~8:00 静默
- @自己 的消息直接让路给主管道（防双发）
- 群消息窗口带消息 ID，支持 `[QUOTE:n]` 真引用

## emoji-hub（表情包收集与检索）

- **收集**：监听群里的图片消息 → 下载（支持 NapCat 本地路径）→ GLM 视觉打标 → 查重（感知哈希）→ 入库
- **检索**：`search(关键词)` 按关键词/情绪/场景打分，供其他插件调用
- **管理指令**：`/表情包库` 查看库存，`/找表情 关键词`
- 需要 `data/fensheng/config.json` 配置视觉模型（GLM-4V 系免费额度即可）：
```json
{"vlm": {"api_key": "你的key", "base_url": "https://open.bigmodel.cn/api/paas/v4", "model": "glm-5.3-flash"}}
```

## 插件协作关系

```
群消息 ──► group-lurker(围观判定) ─┐
   │                              ├─ 同一条消息只会有一条路径回复
   └─@bot ──► AstrBot主管道 ──────┤
                                    ▼
                          persona-humanizer
                          (延迟/节流/连发/引用/表情包解析)
                                    ▼
                              QQ 消息发出
```
