# 指令手册 — Eidolon 全量指令速查

> 分三类：**日常指令**（所有人可用）、**主人专属**（masters.json 白名单）、**调试指令**。
> 大量能力是**被动**的（无需指令），见文末清单。

## 🌟 日常指令（所有人）

### 签到与好感度（twin-checkin）
| 指令 | 说明 |
|---|---|
| `/签到` | 每日签到：连续加成、每日运势、人格化回应（带她当前的日程状态） |
| `/好感度` | 查自己的好感度数值+等级（陌生→眼熟→熟人→好朋友→挚友→很重要的人）+ 签到羁绊 + 排行榜 |
| `/好感度设置 <QQ号> <数值|+增量|-增量>` | 主人直接修改某人好感度（写入情感引擎真实数据） |

### 日程（twin-schedule）
| 指令 | 说明 |
|---|---|
| `/日程` | 看她今天的日程（骰子生成的：几点在干嘛、心情、今日备注） |
| `/日程 新` | 重新摇骰子生成今天（仅主人） |

### 图片记忆（twin-imgmemory）
| 指令 | 说明 |
|---|---|
| `/想起 <关键词>` | 搜她记住的图，如 `/想起 猫`，返回带序号的列表 |
| `/发图 <序号>` | 重发那张图，如 `/发图 2` |

### 表情包（emoji-hub）
| 指令 | 说明 |
|---|---|
| `/表情包库` | 库存统计+情绪分布 |
| `/找表情 <关键词>` | 检索一张表情包（如 无语/猫/就这） |

### 玩耍
| 指令 | 说明 |
|---|---|
| `/戳我` | 测试戳一戳反应（被动：被戳会随机延迟戳回来+小概率回嘴） |

### 点歌（astrbot_plugin_music 社区插件）
| 指令 | 说明 |
|---|---|
| `点歌 <歌名>` | 按音源优先级搜索播放（卡片/语音） |
| `网易云点歌 <歌名>` / `QQ音乐点歌 <歌名>` | 指定平台 |
| `点歌 <歌名> <序号>` | 直接选搜索结果 |
| `查歌词 <歌名>` | 发歌词 |
| `登录QQ音乐` | 管理员扫码接 QQ 音乐音源 |
| 自然语言 | 直接说"来一首晚安曲"也会触发（LLM 工具） |

### 空间浏览（astrbot_plugin_qzone 社区插件）
`/看说说`、`/赞说说`、`/评说说`、`/查看访客` —— 浏览和互动好友动态（发说说类指令见主人区/插件文档）。

## 👑 主人专属指令（twin-master 等）

### 指挥系统
| 指令 | 说明 |
|---|---|
| `/群列表` | bot 所在的所有群 |
| `/看消息 <群号> [条数]` | 拉取群最近消息原文 |
| `/总结聊天 <群号> [条数]` | AI 总结群聊 |
| `/群日报 <群号> [条数]` | 话题榜/活跃人物/今日金句/氛围总结 |
| `/发言 <群号> <内容>` | 让 bot 在指定群主动发言 |
| `/私发 <QQ号> <内容>` | 让 bot 私聊某人 |
| `/打包发言 <群号> [条数]` | 群消息打包成合并转发私发给你 |
| `/总结合并转发` | 总结私聊发给 bot 的合并转发 |

### 空间创作
| 指令 | 说明 |
|---|---|
| `/发空间 [诗/看法/知识] [主题]` | 后台创作+AI配图+公开发布（约1分钟），如 `/发空间 诗 深夜的成都` |
| `/画图 <描述>` / 私聊说"画 xxx" | 聊天生图（仅主人，每天10张） |
| `/写说说` | LLM 随手写一条说说（qzone 插件） |

### 生命管理
| 指令 | 说明 |
|---|---|
| `/生日 <QQ号> <MM-DD> [称呼]` | 登记生日，当天上午自动送祝福 |
| `/自检` | 一键体检：QQ在线/LLM连通/记忆资产/日程状态 |
| `/记忆导出` | 全量记忆打包成 JSON 文件私发给你 |
| `/日程 新` | 重摇今天的日程骰子 |

## 🔧 调试指令（fensheng-plus 语音系统）

| 指令 | 说明 |
|---|---|
| `/fs` | 情感引擎状态总览 |
| `/fs语音 <文本>` | 走生产链路合成语音（MOSS主/edge-tts备），测试音质 |
| `/fs音色` | 音色列表；`/fs音色 序号` 切换默认音色 |

## 🤖 被动能力（无需指令，自动发生）

| 能力 | 触发 |
|---|---|
| 语音回复 | 聊天中她"想发语音"时自动合成（`[[VOICE:]]` 协议） |
| 表情包斗图 | 情绪匹配自动发表情包 |
| 读空气插话 | 群聊激活度评分 ≥6 时主动插话；提她名字高把握接话 |
| 群印象/黑话 | 每群 220 条消息自动总结画像注入 |
| 图片吐槽 | 群里纯图消息 5% 概率被"看到"并吐槽 |
| 表达进化 | 群友正向反应强化她的说法风格 |
| 晚间主动关怀 | 18~23 点看日程空闲主动找主人搭话（每天≤2次） |
| 到期跟进 | "上次说的面试咋样了"自动追踪 |
| 生日祝福 | 当天 9~12 点自动私发 |
| 新好友破冰 | 新好友 40~180s 后主动打招呼+通知主人 |
| 空间互动 | 每天 8 点逛好友说说点赞评论；被评论 15 分钟内自动回评 |
| 记忆成长 | 每 30 轮对话合并档案+写聊天日记 |
| 图片入库 | 私聊图全记/群图 25% 采样（免费 VLM 打标） |
| 风控自愈 | 掉线自动重登+微信推送（见运维文档） |

### 梗与形象知识库（twin-meme）
| 指令 | 说明 |
|---|---|
| `/梗 <词>` | 查梗/形象含义；本地没有自动联网搜并学会 |
| `/学梗 <词> <含义>` | 主人手动教学，立刻入库 |
| `什么是X / X是什么` | 直接问也会答（本地→联网→请主人教） |
| `/这是谁` | **回复一张图**：识别图里的形象/IP，本地不认识就联网搜索确认后记住 |
| 被动 | 对话中命中词条自动注入理解；每天自动上网挖新梗入库；识图带形象提示词 |
