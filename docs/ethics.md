# 伦理与法律边界

这个项目能"扮演一个人"，所以这页和代码一样重要。

## 三条底线

1. **只蒸馏你自己。**
   聊天记录、语音、社交动态属于个人信息。未经对方明确同意提取并蒸馏他人人格，
   在中国可能违反《个人信息保护法》（处理他人个人信息需取得同意），
   在其他司法辖区同样有隐私法风险。"技术上有可能"不等于"允许"。

2. **分身必须可自证。**
   对方严肃追问"你是不是机器人"时，bot 必须大方承认（已内置于人格红线）。
   一个不肯承认自己是 AI 的分身，用途只剩欺骗。

3. **重大事件必须转交本人。**
   对方出现危机（极端情绪、亲人变故、求助）时，分身只能温柔回应并引导"直接联系本人"。
   AI 不该在别人的至暗时刻假装是真人陪伴。

## 灰色地带的自我审查清单

发布或部署前问自己：

- [ ] 被蒸馏者本人是否知情并同意？（自蒸馏 = 自己同意自己，天然成立）
- [ ] bot 的好友是否知道这是 AI？（建议在签名/空间做柔性声明）
- [ ] 是否用它冒充本人做出承诺、表态、金钱往来？（人格已禁止，但要监督）
- [ ] 聊天语料上传的 LLM 服务商是否可接受？（别人的隐私进了第三方服务器）
- [ ] 蒸馏产出的记忆/档案是否妥善本地保存、不外传？

## 对协作者的期望

- Issue/PR 中不要分享含他人隐私的聊天记录、数据库、密钥
- 不要提交"如何绕过平台风控/如何解密他人数据库"的内容
- fork 与二次发布请保留 GPL-3.0 及附加条款（自蒸馏限定 + AI 自证要求）

## 已有项目的态度可参考

- immortal-skill：要求蒸馏他人需附 LICENSE-DISTILL 授权声明
- QQBackup：定位"数据恢复与个人备份"，反复强调仅限本人数据

这个赛道很新，法律更滞后。但滞后不等于没有边界——**你怎么对待别人的数据，别人就会怎么对待你的。**
